# Roadmap

## v0.1 — фундамент (сейчас)
- [x] SDK: контракт, `BinaryReader/Writer`, CRC32, тестовые хелперы
- [x] Devkit, генератор модулей, валидация, CI
- [ ] Первый реальный модуль: Trails in the Sky FC (PC)
- [ ] Второй модуль от внешнего контрибьютора — проверка, что гайда хватает

## v0.2 — богаче контракт
- Типы полей: `flags` (битовые маски), `item-picker` (поиск по большим справочникам), `hex` (сырые байты для «продвинутых»)
- Справочники (`items.json`, `characters.json`) как отдельные данные модуля, общие для рендерера и поиска
- Компрессия и шифрование в SDK: zlib/deflate, AES, распространённые игровые схемы
- Массовые действия в схеме: «максимум всем», «разблокировать всё»

## v0.3 — доверие и качество
- Корпус анонимных сейвов для регрессионных тестов (пользователь по желанию отправляет сейв, на котором модуль упал)
- Автоотчёт об ошибках parse с хэшем файла, без содержимого
- Статусы модулей по обратной связи: experimental → beta → stable
- Дифф «что изменилось» перед скачиванием

## Масштабирование
- **Движки, а не игры.** Много игр делят формат (RPG Maker, Unity `PlayerPrefs`/BinaryFormatter, Unreal `.sav` GVAS, Ren'Py). Общие парсеры движков в SDK → модуль игры становится тонким слоем «какие поля показать».
- **Серии.** Trails/Persona/Yakuza — общая библиотека внутри серии (`modules/_shared/<series>`).
- **Консоли.** Гайды по выгрузке сейвов (JKSV для Switch, Apollo для PS4), поддержка их контейнеров.
- **Сообщество.** Страница контрибьютора на сайте, бейджи, «запросы игр» с голосованием (issues `game-request`), баунти на популярные запросы.
- **Пресеты.** Поделиться набором изменений («100% прохождение», «New Game+») — это просто JSON из путей и значений.
- **Офлайн/десктоп.** PWA, позже десктоп-клиент, который сам находит сейвы по `saveLocations`.
