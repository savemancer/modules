# Roadmap

## Игры к запуску

Критерии: игру ищут; формат можно разобрать без обхода DRM; сейв можно проверить в игре; нет онлайна и античита.

| # | Игра | Формат | Сложность | Проверка в игре | Статус |
|---|------|--------|-----------|-----------------|--------|
| 1 | Trails in the Sky FC | бинарный, без чексуммы | — | ✔ | **beta** |
| 2 | Clair Obscur: Expedition 33 | Unreal Engine 5 GVAS, без сжатия | средняя | ✔ сейвы есть | **experimental** |
| 3 | Stardew Valley | XML | низкая | по сейвам сообщества | **experimental** (синтетический сейв) |
| 4 | Hollow Knight | JSON, AES с публичным ключом | низкая | по сейвам сообщества | **experimental** (синтетический сейв) |
| 5 | Undertale / DELTARUNE | текст построчно | низкая | DELTARUNE установлена | — |
| 6 | Slay the Spire | JSON, base64 + XOR | низкая | по сейвам сообщества | **experimental** (синтетический сейв) |
| 7 | Terraria (персонаж `.plr`) | бинарный, AES с публичным ключом | средняя | по сейвам сообщества | — |
| 8 | Subnautica | JSON + protobuf | высокая | ✔ сейвы есть | — |

Дёшево после первых модулей:

- **Trails in the Sky SC / the 3rd** — тот же движок ED6, что у FC: раскладка похожа, данные игры из тех же архивов.
- **Движок Unreal (GVAS)** — парсер из модуля Clair Obscur переносится в SDK и открывает другие UE-игры
  (Palworld, Persona 3 Reload, Hogwarts Legacy — у части есть сжатие или шифрование поверх GVAS).
- **RPG Maker MV/MZ** — один модуль на тысячи инди-игр: JSON (LZString / zlib), деньги, уровни, предметы по id.

SDK уже умеет: GVAS (Unreal), AES-ECB/CBC, base64, точечную правку JSON (`JsonText`).

**Нужны настоящие сейвы** Hollow Knight, Slay the Spire, Stardew Valley, Terraria, DELTARUNE — модули для первых трёх
собраны по открытым описаниям форматов и проверены только на синтетике.

Не берём: игры с онлайном и античитом (HELLDIVERS 2, онлайн Elden Ring), Witcher 3 и Control — пока
(сложные проприетарные форматы), игры для взрослых — бренд-риск.

## v0.1 — фундамент (сейчас)
- [x] SDK: контракт, `BinaryReader/Writer`, CRC32, тестовые хелперы
- [x] Devkit, генератор модулей, валидация, CI
- [x] Первый реальный модуль: Trails in the Sky FC (PC) — beta, проверен в игре
- [ ] Второй модуль от внешнего контрибьютора — проверка, что гайда хватает

## v0.2 — богаче контракт
- Типы полей: `flags` (битовые маски), `item-picker` (поиск по большим справочникам), `hex` (сырые байты для «продвинутых»)
- Справочники (`items.json`, `characters.json`) как отдельные данные модуля, общие для рендерера и поиска
- Компрессия и шифрование в SDK: zlib/deflate, AES, распространённые игровые схемы
- Массовые действия в схеме: «максимум всем», «разблокировать всё»

## v0.3 — доверие и качество
- Корпус анонимных сейвов для регрессионных тестов (пользователь по желанию отправляет сейв, на котором модуль упал)
- Автоотчёт об ошибках parse с хэшем файла, без содержимого
- Статусы модулей по обратной связи: experimental → beta → stable
- Дифф «что изменилось» перед скачиванием

## Масштабирование
- **Движки, а не игры.** Много игр делят формат (RPG Maker, Unity `PlayerPrefs`/BinaryFormatter, Unreal `.sav` GVAS, Ren'Py). Общие парсеры движков в SDK → модуль игры становится тонким слоем «какие поля показать».
- **Серии.** Trails/Persona/Yakuza — общая библиотека внутри серии (`modules/_shared/<series>`).
- **Консоли.** Гайды по выгрузке сейвов (JKSV для Switch, Apollo для PS4), поддержка их контейнеров.
- **Сообщество.** Страница контрибьютора на сайте, бейджи, «запросы игр» с голосованием (issues `game-request`), баунти на популярные запросы.
- **Пресеты.** Поделиться набором изменений («100% прохождение», «New Game+») — это просто JSON из путей и значений.
- **Офлайн/десктоп.** PWA, позже десктоп-клиент, который сам находит сейвы по `saveLocations`.
