# Savemancer Modules

Открытые модули игр для [Savemancer](https://savemancer.com) — онлайн-редактора сохранений.

Сайт и API закрыты, а вся логика работы с конкретными играми — здесь, под MIT.
Нет вашей игры? Напишите модуль — после ревью он появится на сайте.

## Как это работает

```
 браузер пользователя
 ┌──────────────────────────────────────────────────────────┐
 │  UI сайта (закрыт)              Web Worker (без сети)     │
 │  ┌───────────────┐  файлы  ┌──────────────────────────┐   │
 │  │ выбор игры    │ ──────▶ │ модуль игры (этот репо)  │   │
 │  │ форма по схеме│ ◀────── │ parse → schema           │   │
 │  │ «скачать»     │ ──────▶ │ serialize → новые байты  │   │
 │  └───────────────┘         └──────────────────────────┘   │
 └──────────────────────────────────────────────────────────┘
```

- **Сейв не покидает компьютер пользователя.** Модуль выполняется в браузере, сервер видит только каталог модулей.
- **Модуль не пишет UI.** Он описывает поля декларативной схемой (`number`, `text`, `select`, `list`…), сайт рисует форму сам.
- **Модуль — чистые функции над байтами:** без сети, DOM, таймеров. Это проверяется статически (`npm run validate`) и песочницей на сайте.

## Быстрый старт

```sh
npm install
npm run new-module -- persona-3-reload "Persona 3 Reload"
npm run dev        # devkit на http://localhost:5173 — откройте свой сейв и проверьте редактор
npm run check      # валидация + типы + тесты — то же, что в CI
```

Подробно — в [CONTRIBUTING.md](CONTRIBUTING.md). Устройство — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), деплой — в [docs/DEPLOY.md](docs/DEPLOY.md).

## Структура

| Путь | Что это |
|------|---------|
| `packages/sdk` | Типы контракта, `BinaryReader/Writer`, чексуммы, тестовые хелперы |
| `packages/devkit` | Локальный редактор для разработки модулей |
| `modules/<id>` | Модули игр |
| `modules/example-rpg` | Учебный модуль на вымышленном формате |
| `templates/module` | Шаблон для `npm run new-module` |
| `scripts/` | Валидация, сборка `dist/registry.json` |
