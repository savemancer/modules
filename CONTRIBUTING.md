# Как добавить игру

## 1. Создайте модуль

```sh
npm run new-module -- <id> "<Название игры>"
```

`id` — kebab-case, уникален, включает часть/издание, если их несколько: `trails-in-the-sky-fc`, `persona-3-reload`.

## 2. Опишите модуль

`modules/<id>/module.json` — метаданные: платформы, какие файлы принимаются (`files`), где пользователю их искать (`saveLocations`). Сайт показывает это до загрузки кода.

`modules/<id>/src/index.ts` — четыре функции:

| Функция | Что делает |
|---------|-----------|
| `detect(files)` | Быстрая проверка, что это сейв этой игры (magic, размер). |
| `parse(files)` | Байты → plain-объект. При неизвестном формате бросает `SaveFormatError`. |
| `schema(data)` | Какие поля показывать: вкладки, числа с `min/max`, списки, выпадающие списки. |
| `serialize(data, original)` | Объект → байты. **Патчите копию `original`**, а не собирайте файл с нуля: неизвестные байты должны остаться нетронутыми. Не забудьте пересчитать чексумму. |

Опционально `validate(data)` — проверки сверх `min/max` (например, HP ≤ max HP).

Образец — [modules/example-rpg](modules/example-rpg).

### Правила

- Только `@savemancer/sdk` и относительные импорты. Нужна библиотека (zlib, AES) — откройте issue, добавим в SDK.
- Без сети, DOM, хранилищ, таймеров, `eval`. Это проверяет `npm run validate`.
- Данные из `parse` — plain-объекты (без классов и функций), они передаются через `postMessage`.
- Шифрование сейвов — ок, если ключ публично известен и используется только для чтения/записи сейва. Обход DRM, античитов и онлайн-проверок не принимаем.
- Никаких ассетов игры (картинки, тексты из ресурсов) — только названия предметов/персонажей, необходимые для UI.

## 3. Тесты

Обязательно:

- `roundTrip` — `parse → serialize` без изменений даёт байт-в-байт исходный файл;
- `checkSchema` — все пути схемы существуют в данных;
- хотя бы один тест на редактирование: изменили поле → сохранили → перечитали → значение на месте.

Кладите реальные сейвы в `modules/<id>/fixtures/` (до 1 МБ, без никнеймов и аккаунтов в данных).

## 4. Проверьте вживую

```sh
npm run dev
```

Выберите модуль, перетащите сейв, измените поля, скачайте и **загрузите сейв в игре**. В описании PR укажите, на какой версии игры и платформе проверяли.

## 5. Pull Request

`npm run check` должен проходить. Мейнтейнер проверит код (особенно `serialize`), прогонит на своих сейвах при возможности и смёржит. Новый модуль выходит со статусом `experimental`, `stable` — после подтверждений от пользователей.
