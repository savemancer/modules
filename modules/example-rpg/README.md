# Example RPG

Учебный модуль на вымышленном формате. Используйте как образец при написании своего.

## Формат `.xsav` (little-endian)

| Offset | Размер | Поле |
|-------:|-------:|------|
| 0x00 | 4 | magic `XRPG` |
| 0x04 | 2 | версия формата (= 1) |
| 0x06 | 2 | число персонажей в партии |
| 0x08 | 4 | золото |
| 0x0C | 4 | время игры, секунды |
| 0x10 | 32 × N | персонажи (см. ниже) |
| конец − 4 | 4 | CRC-32 всех предыдущих байтов |

Персонаж (32 байта): имя ASCII 16 байт · `u8` уровень · `u8` класс · `u16` HP · `u16` max HP · `u16` MP · 8 байт неизвестно (сохраняются как есть).
