# Hollow Knight

ПК-версия (Steam/GOG, Windows/Linux/macOS). Сохранения Switch и консолей не зашифрованы так же — не поддерживаются.

## Формат `user*.dat`

1. Заголовок .NET BinaryFormatter (22 байта: `00 01 00 00 00 FF FF FF FF 01 00 … 06 01 00 00 00`).
2. Длина строки в формате 7-bit varint (LengthPrefixedString).
3. Строка base64 от AES-256-ECB с PKCS#7, ключ `UKu52ePUBwetZ9wNX88o54dnfKRu0T1l` (публично известен).
4. Байт `0x0B`.

Внутри — JSON Unity (`{"playerData":{…},"sceneData":{…}}`). Модуль меняет только значения нужных полей,
остальной текст (включая форматирование чисел) сохраняется как есть; без изменений возвращаются исходные байты.

Формат описан по открытому редактору [bloodorca/hollow](https://github.com/bloodorca/hollow) (код не заимствован).

## Статус

**experimental**: тесты на синтетическом сейве, собранном независимым энкодером (`node:crypto`).
Нужна проверка на настоящих сейвах: имена полей `playerData` и нумерация амулетов взяты из открытых источников.
Редактор показывает только поля, которые реально есть в файле.
