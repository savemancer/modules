# The Legend of Heroes: Trails in the Sky FC

Steam-версия (`ed6_win.exe`, appid 251150). Проверено на сейвах размером 212 160 байт.

## Проверено в игре (0.2.0)

| Правка | Результат |
|---|---|
| Мира 7976 → 50000 (глава 1) | ✔ отображается 50000 |
| Уровень Эстель 24 → 30 (глава 3) | ✔ L30, EXP 9000, NEXT 9610; HP макс. и характеристики игра пересчитала сама |
| Уровень Эстель 7 → 15 (пролог) | ✔ сейв загружается |
| Maple Cookie 1 → 6 (пролог) | ✔ сейв загружается |

Фикстура `early.sav` — ручной сейв пролога, который падает при загрузке в текущей версии игры **и без правок**;
для тестов разбора он годится, для проверки в игре — нет.

## Где лежат сейвы

Сохранения синхронизируются через Steam Cloud и лежат в `Steam/userdata/<ID Steam>/251150/remote/FC/`:
`Auto0.sav`…`Auto9.sav` — автосохранения, `SVDAT###.SAV` — ручные.

**Отредактированным файлом нужно заменить уже существующий сейв.** Игра получает список файлов через Steam Cloud,
и новый файл (например, `SVDAT003.SAV` в пустой слот) она не увидит.

**Перед заменой файла закройте игру.** Если Steam при следующем запуске предложит выбрать между локальной
и облачной версией — выберите локальную.

## Формат (little-endian, контрольной суммы нет)

| Offset | Размер | Поле |
|-------:|-------:|------|
| 0x00000 | 3 × f32 | позиция героя на карте |
| 0x0000C | u32 | счётчик игрового времени |
| 0x23E38 | 8 × u32 | отряд: id персонажа или 0xFF |
| 0x23E58 | 8 × 52 | персонажи (порядок: Estelle, Joshua, Scherazard, Olivier, Kloe, Agate, Tita, Zin) |
| 0x24C88 | 1024 × (u16 id, u16 кол-во) | инвентарь, заполнен с начала без пропусков |
| 0x25C88 | u32 | мира |
| 0x25C8C | u16 | BP (очки гильдии брейсеров) |
| 0x25C90 | 7 × u32 | сепиты: земля, вода, огонь, ветер, время, пространство, мираж |

Запись персонажа (52 байта): `u16` level, HP max, HP, EP max, EP, CP · `u32` EXP (+0x0C) ·
`u16` STR, DEF, ATS, ADF, DEX, AGL, MOV, SPD (+0x10…+0x1E) · `u16` CP max (+0x20) · остальное не исследовано.

Отсутствие контрольной суммы проверено перебором (суммы байт/слов, CRC32) по нескольким сейвам.

## Данные игры

`src/data.ts` сгенерирован из `ED6_DT02.dat` (`T_ITEM`, `T_ITEM2`, `T_EXP`, `T_STATUS`): только названия предметов
и числовые таблицы.

- Порог EXP для уровня N — `EXP_TABLE[N]` = 10·N² (сверено с сейвами: Эстель L7 / 562 EXP, Агата L26 / 6941 EXP).
  Последний порог — уровень 55.
- **Игра пересчитывает HP/EP/CP макс. и характеристики при загрузке** по уровню и экипировке — в файле лежит кэш.
  Проверено: после смены уровня 24 → 30 модуль записал HP макс. 1587 / STR 160 / DEF 134 / ATS 120,
  игра показала 1630 / 162 / 132 / 124. Поэтому в редакторе эти поля только для чтения.
- Уровень, EXP, текущие HP/EP/CP игра берёт из файла как есть (NEXT в игре = 10·(N+1)², что подтверждает таблицу EXP).
- При смене уровня модуль ставит EXP на порог, а кэш характеристик и HP — на оценку по таблице роста
  (база + прежний бонус экипировки). Поля, которые пользователь поменял вручную, не трогаются.

## Что можно редактировать

- мира, BP, сепиты;
- уровень, EXP и текущие HP/EP/CP всех 8 персонажей (характеристики игра пересчитывает сама);
- количество любого из 366 предметов (0 — убрать предмет). Порядок уже имеющихся предметов сохраняется.

Состав отряда не редактируется.
