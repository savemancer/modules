# Clair Obscur: Expedition 33

Steam-версия (Unreal Engine 5.4.4). Проверено на 22 сейвах акта I.

## Где лежат сейвы

`%LOCALAPPDATA%\Sandfall\Saved\SaveGames\<ID Steam>\EXPEDITION_0.sav` — основной слот,
`Backup\` — автоматические резервные копии игры. `SavesContainer.sav` — только оглавление для меню загрузки
(время, карта, отряд); его менять не нужно.

## Формат

GVAS (UE 5.4, версия файла UE5 1012) с «полными именами типов» в тегах свойств — разбирается общим
парсером `parseGvas` из SDK; parse → serialize даёт байт-в-байт исходный файл на всех проверенных сейвах.

| Свойство | Тип | Что это |
|---|---|---|
| `Gold` | Int | золото |
| `CharactersCollection` | Map<Name, S_jRPG_CharacterSaveState> | персонажи: `CurrentLevel`, `CurrentExperience` (прогресс внутри уровня), `AssignedAttributePoints` |
| `InventoryItems` | Map<Name, Int> | все предметы: материалы, расходники, оружие, пиктосы, косметика |
| `TimePlayed` | Double | время игры, секунды |

Внутреннее имя Гюстава — `Frey`.

### Наблюдения по сейвам

- Очки атрибутов: на каждом уровне +3 (сумма распределённых = 3 × уровень у всех персонажей, когда очки потрачены).
  Свободные очки игра вычисляет сама — отдельного поля нет.
- `ECharacterAttribute`: используются значения 0, 1, 3, 4, 5. Соответствие атрибутам (Vitality, Might, Agility,
  Defense, Luck) — **предположение, требует проверки в игре**.
- Опыт хранится как прогресс внутри уровня и обнуляется при повышении.

## Что можно редактировать

- золото;
- уровень и опыт персонажей (при смене уровня опыт начинается с нуля, новые очки атрибутов распределяются в игре);
- распределённые очки атрибутов;
- количество накапливаемых ресурсов. Добавлять можно только ресурсы, чьи ID встречались в реальных сейвах.

Оружие, пиктосы, косметика и квестовые предметы не редактируются (но сохраняются как есть).
