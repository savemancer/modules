# Slay the Spire

ПК-версия. Редактируется сохранение текущего забега `<ПЕРСОНАЖ>.autosave`.

**Выйдите в главное меню (Save & Quit), закройте игру**, замените файл и продолжите забег.

## Формат

`base64(JSON XOR "key")` — ключ `key` повторяется по байтам. Старые версии и моды могут хранить JSON без кодирования —
модуль поддерживает оба варианта и записывает файл в том же виде, в каком получил.
Правятся только значения полей, остальной JSON сохраняется побайтно; без изменений возвращаются исходные байты.

Формат описан по [libsts](https://docs.rs/crate/libsts/latest) и [spireslayer](https://github.com/rahmatnazali/spireslayer) (код не заимствован).

## Статус

**experimental**: тесты на синтетическом забеге, закодированном независимым энкодером. Нужна проверка на настоящих сейвах.
Показываются только поля, которые есть в файле.
