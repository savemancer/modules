# Stardew Valley

ПК-версия 1.5/1.6, несжатые сейвы. Редактируется основной файл фермы `<Имя>_<число>` (без расширения), не `SaveGameInfo`.

## Формат

XML от .NET XmlSerializer: `<SaveGame>` → `<player>` → поля фермера. Модуль правит только текст прямых потомков
`<player>` (одноимённые теги во вложенных элементах — предметах, животных — не затрагиваются) и
`<experiencePoints><int>` (порядок: земледелие, рыбалка, собирательство, шахтёрство, бой, удача).
Остальной документ сохраняется побайтно; без изменений возвращаются исходные байты.

Пути полей сверены с [Stardew Checkup](https://github.com/MouseyPounds/stardew-checkup) (MIT, код не заимствован).
Пороги опыта уровней 1–10: 100, 380, 770, 1300, 2150, 3300, 4800, 6900, 10000, 15000.

## Ограничения

- Сжатые сейвы (zlib) — не поддерживаются.
- При «прыжке» через 5-й и 10-й уровни навыка игра не предложит выбрать профессию.
- В мультиплеере с общим кошельком деньги фермы могут храниться не у игрока — проверяйте на одиночной игре.

## Статус

**experimental**: тесты на синтетическом сейве. Нужна проверка на настоящих сейвах.
